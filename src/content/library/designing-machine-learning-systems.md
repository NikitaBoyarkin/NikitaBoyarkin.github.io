Книга про жизненный цикл ML-системы: данные, признаки, деплой, мониторинг, дрейф. Полезна не столько моделями, сколько рамкой — она заставляет задавать вопрос «что с этим будет через полгода в проде» ещё на этапе постановки задачи.
