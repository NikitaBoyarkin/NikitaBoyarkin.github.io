<h2 id="who" data-analytics-section="who">Who I am</h2>

Nikita Boyarkin, data and product analyst. Focus — experiments, retention and segmentation: from hypothesis to metric, with code and SQL sitting next to every conclusion.

I came to analytics from work psychology (PhD, 2022–2025), which is why I start with "what exactly are we measuring" and only then run the numbers. There is no employer history on my CV — the portfolio is built from project work on synthetic and open data.

<h2 id="how" data-analytics-section="how">How I work</h2>

From hypothesis to metric. Every conclusion can be re-checked: code, SQL and visualization sit next to each case, so you verify the calculation instead of trusting the number.

The methodology is reproducible: CUPED, AA-tests, multiple-comparison correction, ship-gates. I would rather have a pre-registered MDE stop a decision than a lucky chart.

<h2 id="work" data-analytics-section="work">How to work with me</h2>

<p class="wwm-sub">A relationship manual — so we don't waste time figuring out the format.</p>

<div class="bento-grid">
<div class="board-card wwm-block">
  <h3>Values</h3>
  <ul>
    <li><b>Honesty with data</b> — if the numbers contradict the hypothesis, we change the hypothesis, not the numbers.</li>
    <li><b>Speed of learning</b> — try fast, learn fast, record the result.</li>
    <li><b>Direct feedback</b> — no euphemisms, no "I feel like".</li>
  </ul>
</div>

<div class="board-card wwm-block">
  <h3>Working style</h3>
  <ul>
    <li>I like context before a request: why, for whom, what decision the result will drive.</li>
    <li>I ask clarifying questions — 5 questions up front beat rework at the end.</li>
    <li>I prefer metrics over impressions: "up 6pp" instead of "it got better".</li>
  </ul>
</div>

<div class="board-card wwm-block">
  <h3>What matters to me in a team</h3>
  <ul>
    <li>Data-driven decisions — metrics as the language, not decoration.</li>
    <li>Metric ownership — the team knows what it measures and why.</li>
    <li>An experimentation culture — hypotheses get tested, not debated.</li>
  </ul>
