# Volta — Анализ трат

## Ситуация

Где и на что уходят деньги клиентов — база для cashback- и офферной стратегии.

## Задача

Мне нужно было отвечать за структуру разбивки трат и за её пригодность для продуктовых решений.

## Действия

Траты я разложил по нескольким осям сразу, чтобы за общей суммой был виден и тип расхода, и канал, и конкретный мерчант.

- **Агрегация.** Свёл транзакции в разбивки по категориям, каналам и мерчантам — один и тот же оборот читается с трёх сторон.
- **Частота против объёма.** Сравнил категории по числу транзакций и по сумме, чтобы не путать самую частую категорию с самой крупной.
- **Средний чек.** Посчитал средний чек по категориям, чтобы увидеть разницу между частыми мелкими и редкими крупными тратами.
- **Отказы.** Добавил долю отказов по категориям как отдельный сигнал о качестве оплаты, а не только о спросе.
- **Динамика.** Построил месячный тренд, чтобы отличить устойчивый сдвиг от разового всплеска.
- **Инструменты.** Python и pandas/NumPy для агрегаций, Matplotlib/Seaborn для разбивки и тренда.

## Результат

- **Bills (25,8%)** и **travel (20,2%)** — крупнейшие категории; вместе почти половина оборота.
- **Groceries** — самая частая (18 238 транзакций, средний чек €45,8).
- Travel — тонкая маржа (см. Project 14).

## Рекомендации

- Строить cashback/офферы вокруг топ-категорий (bills, groceries).
- Следить за маржой travel при росте объёма.
- Мониторить decline rate как индикатор UX оплаты.
