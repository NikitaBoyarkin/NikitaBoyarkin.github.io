## 1. Проблема

Canvas-гейт работает: `index.astro` → `PersonaCanvas`, фит узлов, три темы, JS-off стопка,
`--border-active` на интерактивных границах, гейт пройден (`docs/superpowers/plans/2026-10-10-canvas-homepage.md`).
Спека закрыла **механику** — она не закрывала **композицию**.

Аудит 2026-10-10 (скриншоты + `getBoundingClientRect`) дал восемь находок. Две из них
при сверке с кодом 2026-10-10 отпали или повисли — они оставлены в таблице §5 явно, вместе с
классом доказательства, чтобы следующая сессия не чинила несуществующее.

**Три поправки к аудиту, найденные сверкой:**

1. **Опровергнуто.** «Тулбар зума висит поверх стопки на телефоне» — неверно:
   `global.css:3845` гасит `.canvas-controls` внутри `max-width: 899px`, а `global.css:3873` —
   в `html.canvas-static`. На телефоне контролов нет ни в живой, ни в JS-off ветке.
2. **Не проверено.** `docH = 1172` при вьюпорте 900 (`100vh` + `overflow: hidden`). Причина
   не установлена, probe не прогонялся.
3. **Замеры «до» из брифа 2026-10-05 недействительны.** `main 6764px`, карточка `372×897`,
   `y=536` — снимок другой страницы (до решений 2 и 3 на `/projects/`). Как baseline не годятся.

## 2. Цель

1. Левая и правая колонки читаются как одна композиция: совпадает верх, нет пустого провала.
2. Три ролевые карточки перестают быть близнецами — видно, какая ведёт куда.
3. Рамки-скетчи перестают спорить с содержимым; в светлой теме не пропадают.
4. Коралл `#ff8569` тратится только на действие, не на декор (`DESIGN.md:120`).
5. Проза внутри карточки — `--text-normal`, не `--text-muted` (`DESIGN.md:124`).
6. Светлая тема: карточки не читаются как грязно-серые на кремовом.
7. Механику не ломаем: `tests/built/canvas.test.ts` остаётся зелёным.

## 8. Критерии приёмки

1. Верх левой и правой колонок на одной линии (C1).
2. Вертикальный провал под CTA ≤ 100px вместо ~290 (C2).
3. Три ролевые карточки различимы по назначению, новых компонентов не появилось (C3).
4. Проза в карточке вычисляется как `--text-normal` (C4).
5. Коралл не появляется ни на одном декоративном элементе холста (C5).
6. Карточка в светлой теме не читается серой заплатой на кремовом (C6).
7. C8 закрыт механизмом **или** явно помечен «intended, not enforced» с причиной.
8. `contrast-gate.js` зелёный на `global.css` в тёмной и светлой темах.
9. `tests/built/canvas.test.ts` ≥ 118 pass / 0 fail; ни один существующий ассерт не удалён и не ослаблен.
10. Ни один `.canvas-node` не выходит за `1440×900` и не шире вьюпорта на 375 / 390 / 412px.

## 9. Риски

| Риск | Смягчение |
|---|---|
| Сдвиг координат ломает фит: узлы вылезают за мир или пересекаются | `tests/lib/canvas-layout.test.ts` уже это держит — падение называет виновный бокс |
| Правка `global.css` блокируется `contrast-gate.js` (AA 4.5:1 текст / 3:1 не-текст) | Считать ratio до правки, а не после |
| Светлая тема не воспроизводится локально: LHCI не эмулирует `prefers-color-scheme` | Снимать обе темы явно, через `localStorage.theme` |
| Два списка сброса стопки обязаны совпадать дословно (`PersonaCanvas.astro` + `global.css`) | `tests/built/canvas.test.ts` сравнивает их; при правке одного — править оба |
| Композицию правят по старым скриншотам | Ф0 обязателен: снимки 2026-10-10 устарели после `b28c867` и `1d2421d` |
| Иерархия карточек сползает в новый компонент | §3 прямо это запрещает; Q5 — внутри `.persona-card` |
