## 1. Executive Summary

Главная страница (RU и EN) отдаёт в соцсети превью `portfolio-graph-v1.png` — SVG-баннер 1200×630,
правая панель которого рисуется из **реального** контент-графа. Баннер собран изолированно от
дизайн-системы сайта: набран Helvetica Neue вместо Inter/Cormorant, не проходит WCAG AA по
оранжевому тексту, а правый граф в превью ~500px читается как «клубок» линий, а не структура.

Документ фиксирует рестайл: привести баннер к системному слою `DESIGN.md` (типографика, ритм,
радиусы, «accent семантичен»), починить AA-контраст, приглушить шум графа и выделить хабы —
не меняя палитру, пайплайн `rsvg-convert`, данные графа и размер. Вторым шагом тот же язык
переносится на `portfolio-banner-v2.png`, чтобы два баннера читались как серия.

## 2. Problem Statement

### 2.1 Текущая ситуация `[V]`

| Факт | Источник |
|---|---|
| Главные RU/EN отдают `og:image = /images/og/portfolio-graph-v1.png` | `src/pages/index.astro:69`, `src/pages/en/index.astro:69` |
| Fallback всех остальных страниц — `portfolio-banner-v2.png` | `src/layouts/Base.astro:32` |
| Баннеры генерируются вручную, в билд не вшиты | `package.json:17–21`; шапки скриптов; `.github/workflows/deploy.yml` OG-скрипты не вызывает |
| Шрифт баннера — `'Helvetica Neue', Helvetica, Arial` (fontconfig) | `scripts/generate-graph-og.mjs:80`, `scripts/generate-home-og.mjs:31` |
| Сайт использует Inter (variable 100–900) и Cormorant (variable 400–700), оба только `.woff2` | `src/styles/global.css:10,41`; `public/fonts/*.woff2` |
| Имя в hero на сайте — display-serif | `src/styles/global.css:827` (`font-family: var(--font-display)`), `src/styles/global.css:109–110` |
| OG-изображения не покрыты тестами и Lighthouse | grep по `tests/`, `.lighthouserc.json` — совпадений нет |

### 2.2 Три дефекта `[V]`

- **P1 — Типографика вне системы.** `rsvg-convert` не видит Inter/Cormorant: в fontconfig этих
  семейств нет, а `.woff2` fontconfig не читает. Баннер набран Helvetica, тогда как identity-шрифт
  сайта — Cormorant (`--font-display`).
- **P2 — Оранжевый текст не проходит AA.** Замеры на фоне `#1400c3`: CREAM `#f8f2da` — **10.29:1**,
  MUTED `#bdb5ea` — **6.03:1**, PERI `#9db4ff` — **5.72:1**, PEACH `#ffb38a` — **6.64:1**,
  ORANGE `#fe4e02` — **3.47:1** (только порог «крупного текста» 3:1). Роль «Product / Data Analyst»
  набрана 22px/600 — это **не** «крупный текст» (нужно ≥18.66px при 700 или ≥24px), значит правило
  AA 4.5:1 нарушено. `DESIGN.md:271` требует AA.
- **P3 — Правый граф нечитаем в превью.** Плотные тонкие рёбра `topic/shared/core` создают шум;
  обрезка по 3%..97% percentile оставляет дальние узлы у кромки, порождая длинные «случайные» линии
  (та голубая струна у нижнего края); нет акцента на хабах; поверхность графа не отделена от фона.

### 2.3 Влияние

- **Кто затронут:** рекрутёр/нанимающий, который видит превью в LinkedIn/X/Telegram; автор, чей
  бренд-сигнал размывается непрошедшим AA и «шумным» графом.
- **Как затронут:** превью ~500px не передаёт структуру портфолио — теряется ключевой нарратив
  «граф контента».
- **Серьёзность:** Medium. Функциональность не ломается, но страдает первый экран бренда и
  доступность.

### 2.4 Почему решать сейчас

Баннер уже используется как `og:image` главной; палитра стабильна; шрифты сайта —
самохостящиеся (путь вендоринга тривиален). Правка изолирована: 3 существующих файла + 1 новый
каталог ассетов.

## 3. Goals & Success Metrics

### Goal 1 — Типографика соответствует системе сайта
- **Метрика:** какие семейства фактически используются рендерером.
- **Baseline:** Helvetica Neue (`generate-graph-og.mjs:80`).
- **Target:** имя — Cormorant 600; служебный текст — Inter 400/500/600/700.
- **Метод:** рендер + визуальная сверка; `fc-match`/отсутствие warning'ов fontconfig.

### Goal 2 — Нет текста ниже WCAG AA
- **Метрика:** contrast ratio каждого текстового токена к фону `#1400c3`.
- **Baseline:** ORANGE-роль 3.47:1 — FAIL.
- **Target:** все текстовые элементы ≥4.5:1 (или ≥3:1 при явном «крупном» кегле/жирности).
- **Метод:** таблица контраста, печатаемая скриптом; ассерт в коде.

### Goal 3 — Граф читается как структура в превью ~500px
- **Метрика:** субъективная разборчивость + отсутствие артефактных линий.
- **Baseline:** «клубок», есть длинные случайные рёбра к выбросам.
- **Target:** рёбра `topic/shared/core` приглушены; хабы выделены; узлы degree ≤ 1 отброшены;
  поверхность графа отделена панелью.
- **Метод:** превью 1200px и даунскейл ~500px на ревью.

### Goal 4 — Два баннера читаются как серия
- **Метрика:** совпадение type/accent/surface-языка.
- **Target:** home-OG получает те же шрифты, CREAM-роль, AA и surface-правило; композиция
  (портрет-гексагон + retention-кривая) сохраняется.
- **Метод:** визуальная парная сверка.

## 6. Requirements

Обозначения: **P0** — must have, **P1** — should have, **P2** — nice to have.

### REQ-01 (P0) — Шрифтовой слой OG
Статические TTF Inter (400/500/600/700) и Cormorant (600/700) лежат в `scripts/og-fonts/` вместе с
`fonts.conf` и `OFL.txt`. Скрипты выставляют `FONTCONFIG_FILE` при вызове `rsvg-convert`.
- **Критерий:** рендер баннера даёт Cormorant в имени и Inter в служебном тексте (визуальная
  сверка), в выводе нет fontconfig-fallback warning'ов.

### REQ-02 (P0) — Типографическая раскладка граф-баннера
- Имя «Nikita Boyarkin» — Cormorant 600, ~60px, letter-spacing ≈ −0.5.
- Роль «Product / Data Analyst» — Inter 600, **CREAM**, ~24px.
- Секция «ГРАФ КОНТЕНТА» — Inter 700, letter-spacing ≈ 3px, CREAM, ~15px.
- Дескриптор (2 строки) — Inter 400/500, MUTED, ~15px, lh ≈ 1.4.
- Легенда — Inter 500, MUTED, 16px; точки сохраняют цвета категорий.
- URL — Inter 500, CREAM, ~22px.
- **Критерий:** перечисленные пары (роль/кегль) присутствуют в SVG-разметке скрипта.

### REQ-03 (P0) — WCAG AA для всего текста
- **Критерий (механический):** скрипт бросает ошибку, если contrast ratio любого текстового токена
  к фону < 4.5:1 (или < 3:1 при явно «крупном» кегле). Эталонные замеры: CREAM 10.29, MUTED 6.03,
  PERI 5.72, PEACH 6.64, ORANGE 3.47.

### REQ-04 (P0) — Поверхность граф-панели
- Клип радиус 20; рамка 1px (край ≈ 0.14); мягкая внутренняя vignette (края темнее центра);
  оранжевый radial glow приглушён до ≤0.08.
- **Критерий:** атрибуты рамки/vignette присутствуют в SVG; glow ≤0.08.

### REQ-05 (P0) — Читаемость графа (presentation-only)
- Рёбра `topic/shared/core` приглушены; `related/children` остаются проминентными.
- Топ-узлы по degree визуально акцентированы (размер и/или обводка).
- Узлы с degree ≤ 1 / выбросы отбрасываются **в статичной картинке**; данные графа не меняются.
- **Критерий:** в скрипте есть явный фильтр и комментарий «presentation-only»; `buildGraph`,
  `layoutGraph`, `TOPICS` не изменены (diff пуст).

### REQ-06 (P1) — Подписи якорных узлов
- 3–5 подписей топ-хабов — только если читаемы в превью ~500px.
- **Критерий:** решение зафиксировано по результату визуальной проверки; при нечитаемости —
  не включаются (и это отмечается в §10).

### REQ-07 (P0) — Артефакты и ссылки
- Выход граф-баннера — `public/images/og/portfolio-graph-v2.png`.
- Ссылки обновлены: `src/pages/index.astro:69`, `src/pages/en/index.astro:69`.
- **Критерий:** `grep -rn "portfolio-graph-v1" src/` пуст; новый файл существует, размеры 1200×630.

## 7. Technical Considerations

### 7.1 Пайплайн шрифтов (ключевой риск)
`rsvg-convert` использует fontconfig и **не поддерживает** `@font-face`/`.woff2`. Решение: локальный
`fonts.conf` с `<dir>` на `scripts/og-fonts/` + `FONTCONFIG_FILE` в окружении `spawnSync`.
Альтернатива (отклонена по D3): смена рендерера — в системе есть `resvg`, `sharp`, `playwright`,
но это нарушает «без новых зависимостей и headless-браузера».

### 7.2 Почему статические TTF, а не variable
Оба шрифта на сайте — variable (`global.css:10,41`), но pango/`rsvg-convert` не гарантирует выбор
веса из variable-оси. Статические начертания детерминированы (D4). Сабсетинг — опционально.

### 7.3 Общий хелпер
Шрифтовая обвязка + контраст-ассерт нужны трём OG-скриптам. Кандидат: `scripts/lib/og-render.mjs`.
Решение — implementation detail, может быть отклонено в пользу дублирования ~15 строк.

### 7.4 Совместимость
`rsvg-convert 2.62.3` — единственный обязательный внешний бинарь; документируется в шапке скрипта
(сейчас нигде не задокументирован).

### Шаг 0 — шрифтовой спайк `[V]`

`FONTCONFIG_FILE` **сам по себе не работает** на macOS: `rsvg-convert 2.62.3 → pango
1.58 → cairo` по умолчанию использует бэкенд **CoreText**, который полностью игнорирует
fontconfig. Проверено: с пустым fontconfig (`0` шрифтов) pango всё равно рисовал текст
системным sans. Решение (в рамках D3, без новых зависимостей):

```
FONTCONFIG_FILE    = scripts/og-fonts/fonts.conf
PANGOCAIRO_BACKEND = fc
```

С `PANGOCAIRO_BACKEND=fc` пустой конфиг даёт пустой вывод (config реально читается), а
Cormorant рисуется засечным — спайк пройден. Дополнительно: fontconfig резолвит
относительный `<dir>` относительно **cwd**, поэтому рендер запускается с
`cwd = scripts/og-fonts` (`prefix="cwd"`, чтобы не было warning'а об ambiguous path).
