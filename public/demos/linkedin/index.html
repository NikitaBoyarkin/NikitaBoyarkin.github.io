Ранжируются только серии с n ≥ 3 (min_posts): NBxPlay (n = 2) и Trisigma (n = 1) в рейтинг не попадают. Интервалы — percentile bootstrap по постам, а не по показам: показы детерминированы, как только пост выбран, варьируется только то, какие посты оказались написанными.
